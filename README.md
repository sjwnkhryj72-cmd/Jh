# بوت دراكون للمونتاج (Drakon Video Bot)

هذا البوت يقوم بتصميم الفيديوهات عبر تليجرام باستخدام Python و MoviePy.

## الميزات:
- إضافة تأثيرات أبيض وأسود.
- خاصية التصميم البطيء.
- خاصية عكس الفيديو.

## التشغيل:
1. تأكد من تثبيت المكتبات: `pip install -r requirements.txt`
2. قم بتشغيل البوت: `python main.py`
